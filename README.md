# Complete Lobby System

## Play Button
The Play button allows users to start the game. It is prominently displayed to ensure easy access.

## Nickname Entry
Players can enter their nicknames before starting the game. This helps personalize the gaming experience.

## Game Code Join Box
Inspired by Blooket, players can join games using a unique game code. The join box is user-friendly and straightforward, making it easy for players to connect to ongoing games.
